# HR Employee Turnover Analysis

## Project Overview

This project analyzes employee attrition using Python, Machine Learning, and Power BI. The goal is to identify the factors responsible for employee turnover and help HR make better decisions.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Power BI
- GitHub

---

## Dataset

- IBM HR Employee Attrition Dataset
- Total Employees: 1470
- Features: 35
- Target Variable: Attrition

---

## Project Workflow

### 1. Data Preprocessing
- Loaded HR employee dataset
- Checked missing values
- Removed duplicates
- Label Encoding
- Data Cleaning

### 2. Exploratory Data Analysis (EDA)
- Employee Attrition Analysis
- Age Distribution
- Gender Analysis
- Department-wise Attrition
- Job Role-wise Attrition
- Monthly Income Distribution

### 3. Machine Learning
- Logistic Regression
- Random Forest Classifier

### 4. Model Evaluation
- Accuracy: 87%
- Precision: 88%
- Recall: 87%
- F1 Score: 0.83
- Confusion Matrix
- Classification Report
- Feature Importance

### 5. Power BI Dashboard
- Total Employees
- Employees Left
- Attrition Rate
- Average Age
- Department-wise Analysis
- Gender-wise Analysis
- Job Role-wise Analysis
- Machine Learning Insights

---

## Business Insights

- Employees working overtime are more likely to leave.
- Lower monthly income is associated with higher attrition.
- Employees with fewer years at the company have higher turnover.
- Sales department has higher employee attrition.
- Younger employees show comparatively higher turnover.
